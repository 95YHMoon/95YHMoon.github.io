구축한 파이프라인의 성능을 검증셋으로 평가하고, 지표별 특징과 분석 결과를 정리했다.

## 평가 지표

- **Field-level Accuracy (필드별 정확도)**: 5개 필드 각각의 완전 일치 여부 (Exact Match)
- **Full-sequence Exact Match (전체 일치율)**: 5개 필드가 모두 정답과 일치하는 비율
- **CER (Character Error Rate, 문자 오류율)**: 편집 거리 기반 오타 비율 (0에 가까울수록 정답과 일치)

실물 데이터와 합성 데이터를 분리하여 평가를 진행했다.

## 실물 데이터 평가 결과

| 필드 | 정확도 (Accuracy) | CER |
|---|---|---|
| quantity | 93.5% | 0.065 |
| inbound_date | 92.5% | 0.054 |
| inbound_no | 92.5% | 0.376 |
| sub_name | 78.5% | 0.273 |
| item_name | 57.0% | 0.290 |
| **전체 (Full-sequence)** | **44.1%** | **0.179** |

## 지표 해석

### 1. 긴 필드 (item_name)
`item_name` 필드의 정확도는 57.0%이지만, CER은 0.290이다. 한두 글자의 오타로 인해 완전 일치(Accuracy) 지표는 낮게 나왔으나, 실제 텍스트 인식 수준은 약 70% 이상이다.
문자열 길이가 긴 필드는 1글자만 틀려도 정확도가 0 처리되므로, CER 지표를 함께 확인해야 실제 성능을 올바르게 파악할 수 있다.

### 2. 짧은 필드 (inbound_no)
`inbound_no` 필드는 정확도 92.5%, CER 0.376을 보였다. 텍스트 길이가 3~4글자로 짧은 필드는 오답 발생 시 CER 수치가 급격히 상승한다.
단문 필드에서는 CER의 민감도가 높으므로 정확도 지표를 우선하여 판단하는 것이 타당하다.

### 3. 주요 결과 요약
- `quantity`, `inbound_date`: 정형화된 서식으로 CER 0.05~0.06 수준의 높은 인식률을 보임.
- `item_name`, `sub_name`: 한글 서술형 필드로 CER 0.27~0.29 수준이며, 사전 기반 오타 보정 로직 적용 가능.
- 전체 일치율(44.1%): 가장 낮은 인식률을 보이는 `item_name` 필드가 전체 일치율의 주요 병목으로 작용함.

## 합성 데이터 평가 특이사항

평가 중 합성 데이터의 인식률이 실물 데이터보다 낮게 나오는 현상이 확인되었다.

| 구분 | 전체 일치율 | CER |
|---|---|---|
| **실물 데이터 (Real)** | **44.1%** | **0.179** |
| **합성 데이터 (Synthetic)** | **15.0%** | **0.379** |

학습 데이터 중 합성 데이터 비중이 더 높았음에도 성능이 낮게 측정된 것에 대해, 현재 GT 매칭 오류나 과도한 증강 노이즈 적용 여부를 원인으로 추정하고 있으며 원인 파악 후 개선할 예정이다.
